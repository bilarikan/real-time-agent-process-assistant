# New customer subscription (fictional)

Prerequisite: the customer account exists. See
[Create an account](/system-navigation/create-account.md).

1. Open **Orders → New order** and choose template `TPL-1000`.
2. In the product picker, add the plan SKU, for example `ACME-PLUS-A`.
3. Check the price, then select **Review**.
4. Complete the [order checklist](/system-navigation/order-checklist.md).
5. Select **Save order**.
